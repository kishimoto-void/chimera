追加したい内容

現在のChimera / Toybox系プロジェクトでは、γ-index、Δ-index、is などの概念・指標の設計と検証を優先している。

これらの設計がある程度固まった段階で、研究実験用のToyboxとは別に、個人的な実験として ChatGPT向けのオリジナル外部メモリプロジェクトを作成する予定である。

仮称は BACKPACK とする。

BACKPACKは、ChatGPTそのものを改変するものではなく、LLMの外部に独立した記憶・状態・履歴を保持し、会話時に参照させることを目的とする。

想定する基本思想は以下。

- LLM本体と外部メモリを分離する
- 外部メモリをユーザー側で保持・管理できるようにする
- 会話から生成された情報を構造化して保存する
- 記憶・事実・主張・推論・未知を可能な限り分離する
- "∅ / UNKNOWN" を明示的に保持する
- 矛盾を単純に上書きせず、必要に応じて履歴として保持する
- GitHub等を利用したバージョン管理を想定する
- 同一LLMに異なる外部メモリを与えた場合の振る舞いの差異を観察可能にする
- 将来的には人格・関係性・世界状態などの長期的変化を記録できる可能性を検討する

ただし、現時点では仕様確定済みのシステムではなく、個人的な研究・実験用プロジェクトとして構想している段階である。

また、これは現行のChimera / T2 / T3 / WASHAWASHA / Capsule等を置き換えるものではない。

むしろ、

Chimera / Toybox = 現象の観測・実験

BACKPACK = 外部記憶を実際に持たせる実験

という位置づけを想定している。

READMEでの表現上の注意

- 完成済みの機能として記述しない
- 「LLMに人格を与える」と断定しない
- 「ChatGPTの内部メモリを再現する」と断定しない
- 現在のChatGPT MemoryとBACKPACKを同一視しない
- 将来的な構想・実験計画として記述する
- 「外部記憶によってLLMの振る舞いにどのような変化が生じるかを観察する」という研究的な表現を優先する
- γ-index / Δ-index / is の設計・検証を先行させ、その後にBACKPACKを個人的に実装する予定であることを明記する
