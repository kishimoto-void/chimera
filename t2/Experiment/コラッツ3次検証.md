1. 概要

本実験は、Collatz型離散力学系を出発点とし、異種構造との比較から生成された差分を、T2における ≌（Correspondence） によって縮小可能か探索した第3次実験である。

第1次・第2次の探索では、

[
C \rightarrow D \rightarrow \Delta \rightarrow Z \rightarrow P2
]

という流れを中心に、異種構造間の差分をMaterialとして扱う可能性を検討した。

第3次ではさらに焦点を絞り、

[
\boxed{
A\not\equiv B
\rightarrow
\Delta
\rightarrow
T
\rightarrow
\Delta'
}
]

という 「差分縮小そのもの」 を検証対象とした。

ここで≌は「似ている」という意味ではなく、

[
\boxed{
\Delta(T(A),T(B))
<
\Delta(A,B)
}
]

を満たす変換探索として定義した。

---

2. 第3次実験の目的

今回の目的はCollatz問題そのものを解決することではない。

主目的は、

1. 構造差を明示的な差分として定義する
2. 同一変換をA/B双方に適用する
3. 固定された差分尺度のもとで差分が縮小するか確認する
4. 縮小が各Scaleで同時に発生するか確認する
5. 縮小過程からResidualが生成されるか調べる
6. Residualから独立したZが発生するか調べる
7. 「差分縮小」と「新構造生成」を区別する

ことである。

5. 縮小≌の定義

今回の≌は、

[
A\not\equiv B
]

に対して同一変換Tを適用し、

[

]

[
B'=T(B)
]

としたとき、

[
\boxed{
D(A',B')<D(A,B)
}
]

なら縮小≌が成立すると定義した。

重要なのは、

- Aだけを変換しない
- Bだけを変換しない
- 差分関数を変更しない
- 比較対象を変更しない

ことである。

13. 縮小≌の第一段階

今回確認できたものは、

[
\boxed{
\text{Distance Reduction}
}
]

である。

すなわち、

[
D(T(A),T(B))
<
D(A,B)
]

が明示的に成立した。

しかし、

[
\boxed{

理由は、今回の変換が、

[

[

となることは比較的自明である。

したがって今回の結果は、

«縮小≌の必要条件を確認した»

と位置付けるのが適切である。

[

[

«縮小≌の演算的成立を確認すると同時に、単純な距離収縮と本当の構造的縮小を区別する必要性を明らかにした実験»
