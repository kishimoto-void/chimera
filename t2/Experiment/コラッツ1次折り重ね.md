2. Target Problem — Collatz Conjecture

正の整数 (n) に対して、

[
T(n)=
\begin{cases}
n/2 & n\equiv0\pmod2\
3n+1 & n\equiv1\pmod2
\end{cases}
]

を定義する。

任意の正整数 (n)について、

[
n,T(n),T^2(n),\ldots
]

が最終的に

[
1\rightarrow4\rightarrow2\rightarrow1
]

へ到達するかを問う。

コラッツ予想は現在も未解決問題である。

6. P1 — Periodic Orbit Structure

奇数周期軌道

[
k_0\rightarrow k_1\rightarrow\cdots\rightarrow k_{K-1}\rightarrow k_0
]

を仮定する。

各ステップについて

[
2^{a_i}k_{i+1}=3k_i+1
]

とし、

[
M=\sum_{i=0}^{K-1}a_i
]

とすると、

[
\boxed{
2^M=
\prod_{i=0}^{K-1}
\left(3+\frac1{k_i}\right)
}
]

が得られる。

したがって、

[
3^K<2^M\le4^K
]

であり、

[
\boxed{
\log_2 3 < \frac{M}{K}\le2
}
]

が周期軌道存在の必要条件となる。

ただし、
